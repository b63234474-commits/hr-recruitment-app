# HR Recruitment Management System

Build a complete internal company HR Recruitment / Applicant Tracking System.

This is an internal company application.

IMPORTANT:
- Do NOT create company registration.
- Do NOT create multi-company registration.
- Do NOT create subscription/payment plans.
- Do NOT create public candidate accounts.
- Candidates do not need to register.
- Only internal HR/recruitment users access the application.
- Use MERN stack.
- Frontend: React + Vite.
- Backend: Node.js + Express.
- Database: MongoDB.
- MongoDB can be managed using MongoDB Compass.

# IMPORTANT DEVELOPMENT RULES

Do NOT create fake buttons.

Every major button must work.

Every form must connect to an API.

Every API must connect to MongoDB.

Do not hardcode candidate/job data in React.

Use MongoDB for persistent data.

Use reusable components.

Use proper error handling.

Use loading states.

Use validation.

Do not put backend code inside frontend.

Do not put MongoDB credentials in frontend.

Do not put secret keys in frontend.

Before creating a new file, check whether an appropriate file already exists.

Reuse existing components instead of duplicating code.

Do not overwrite working functionality unnecessarily.

After every module, test the API and frontend connection.
